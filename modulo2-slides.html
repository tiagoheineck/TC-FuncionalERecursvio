A Limitação Crítica da Composição

⚠️ O Problema da Composição Estática:
Como expressar a função de adição $add(x, y) = x + y$?
Para somar $y$ a $x$, precisamos aplicar o Sucessor $S$ exatamente $y$ vezes:
$$add(x, y) = S(S(\dots S(x)\dots)) \quad [y \text{ vezes}]$$
A Composição é estática. Não podemos desenhar uma quantidade de chamadas que dependa da variável $y$!
🗣️ Versão Humana (Como entender):
"A composição funciona como um circuito fixo montado na fábrica: para somar 3, precisa de 3 caixas; para somar 100, precisa de 100 caixas. Não dá para mudar o tamanho do circuito no meio da execução sem um comando de laço."

Por que usamos as letras $g$ e $h$?

Todo laço for na computação possui duas responsabilidades distintas:
  • $f$: A Função Final → O algoritmo que estamos construindo (ex: $add, mult, fact$).
  • $g$: A Função de BASE ($y=0$) → "Qual é o valor inicial do acumulador antes do laço?" (Pense em Ground/Base).
  • $h$: A Função de PASSO ($y+1$) → "O que fazer a cada volta do laço para avançar um degrau?" (Pense em Helper/Passo).

👉 Notação Formal: $f = R(g, h)$   [onde $g = \text{Base}$ e $h = \text{Passo}$]

Definição Formal da Recursão Primitiva ($R$)

Sejam $g: \mathbb{N}^n \to \mathbb{N}$ (base) e $h: \mathbb{N}^{n+2} \to \mathbb{N}$ (passo). A função $f = R(g, h)$ é definida por: $$\begin{cases} f(\vec{x}, 0) = g(\vec{x}) & \text{[Caso Base: } y = 0 \text{]} \\ f(\vec{x}, y + 1) = h(\vec{x},\, y,\, f(\vec{x}, y)) & \text{[Passo Recursivo: } y + 1 \text{]} \end{cases}$$
🗣️ Versão Humana (Como ler a fórmula):
• Quando $y = 0$: não faça laço nenhum, entregue direto a base $g(\vec{x})$.
• Para dar o passo $y+1$: pegue a entrada $\vec{x}$, o contador anterior $y$ e o acumulador ($acc = f(\vec{x}, y)$), e calcule o próximo valor com a regra $h$.

Mapeamento: $R \leftrightarrow$ Laço for

Formalismo Matemático:

$$f(\vec{x}, 0) = g(\vec{x})$$
$$f(\vec{x}, y+1) = h(\vec{x}, y, \text{acc})$$

Equivalente Imperativo (Python):

def f(x, y):
    acc = g(x) # Caso Base (y = 0)
    for i in range(0, y): # y voltas
        acc = h(x, i, acc)
    return acc
🛡️ Garantia de Totalidade: Como $y$ é um número natural finito fixado antes do início, o laço executa exatamente $y$ passos e sempre termina.

Construção Formal: Adição ($add(x, y) = x + y$)

$$\begin{cases} add(x, 0) = U_1^1(x) \\ add(x, y+1) = S\big(U_3^3(x, y, add(x, y))\big) \end{cases}$$
$$add = R\Big(U_1^1,\, C(S; U_3^3)\Big)$$
🗣️ Versão Humana (Como ler e entender):
• Base ($y=0$): $x + 0 = x$ (capturado pela projeção de identidade $U_1^1$).
• Passo ($y+1$): Pegue o resultado acumulado até agora ($acc$, extraído por $U_3^3$) e aplique o Sucessor ($+1$). Repita $y$ vezes!

Limites: A Função de Ackermann

$$\begin{cases} A(0, n) = n + 1 \\ A(m + 1, 0) = A(m, 1) \\ A(m + 1, n + 1) = A\big(m,\, A(m + 1, n)\big) \end{cases}$$
🗣️ Versão Humana (O Monstro de Ackermann):
• $m=0 \implies +1$; $m=1 \implies +2$; $m=2 \implies 2n$; $m=3 \implies 2^n$; $m=4 \implies \text{Torres de Potências } (2^{2^{\dots}})$.
• A função chama a si mesma dentro do próprio argumento. Ela cresce tão rápido que nenhum laço for pré-calculado consegue computá-la!
